# FreeRTOS 任务通知模块

任务通知是 FreeRTOS 的轻量级IPC机制。每个任务自带一个 32 位通知值，无需额外内存分配。

---

## 1. 头文件

```c
#include "task.h"       // FreeRTOS/include/task.h
```

## 2. 发送通知

```c
// ── 完整版发送 ──
BaseType_t xTaskNotify(
    TaskHandle_t xTaskToNotify,
    uint32_t ulValue,
    eNotifyAction eAction        // 见下方说明
);

// ── 中断中发送 ──
BaseType_t xTaskNotifyFromISR(
    TaskHandle_t xTaskToNotify,
    uint32_t ulValue,
    eNotifyAction eAction,
    BaseType_t *pxHigherPriorityTaskWoken
);

// ── 简化版 (递增通知值) ──
BaseType_t xTaskNotifyGive(TaskHandle_t xTaskToNotify);
BaseType_t xTaskNotifyGiveFromISR(TaskHandle_t xTaskHandle, BaseType_t *pxHigherPriorityTaskWoken);
```

### eNotifyAction 取值

```c
#define eNoAction             0  // 只唤醒，不改变值
#define eSetBits              1  // 按位或
#define eIncrement            2  // 通知值+1
#define eSetValueWithOverwrite   3  // 覆写
#define eSetValueWithoutOverwrite 4  // 不覆写 (通知值已被占用则失败)
```

## 3. 接收通知

```c
// ── 完整版接收 (可获取通知值) ──
BaseType_t xTaskNotifyWait(
    uint32_t ulBitsToClearOnEntry,  // 进入时清除哪些位
    uint32_t ulBitsToClearOnExit,   // 退出时清除哪些位
    uint32_t *pulNotificationValue, // [OUT] 接收到的值
    TickType_t xTicksToWait         // 超时
);

// ── 简化版接收 (仅计数) ──
uint32_t ulTaskNotifyTake(
    BaseType_t xClearCountOnExit,   // pdTRUE=清零, pdFALSE=递减
    TickType_t xTicksToWait
);
```

## 4. 典型用法

### 方式1: 通知计数 (等效于二进制信号量)

```c
// 中断中通知任务
void EXTI0_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    EXTI_ClearITPendingBit(EXTI_Line0);
    vTaskNotifyGiveFromISR(xTaskHandle, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}

// 任务中等待通知
void vTask(void *pvParameters) {
    while(1) {
        ulTaskNotifyTake(pdTRUE, portMAX_DELAY);  // 等待通知
        printf("Got notification!\r\n");
    }
}
```

### 方式2: 通知值传递数据

```c
// 发送任务
void vSender(void *pvParameters) {
    uint32_t value = 0;
    while(1) {
        vTaskDelay(pdMS_TO_TICKS(1000));
        xTaskNotify(xReceiverHandle, value++, eSetValueWithOverwrite);
    }
}

// 接收任务
void vReceiver(void *pvParameters) {
    uint32_t value;
    while(1) {
        xTaskNotifyWait(0, 0, &value, portMAX_DELAY);
        printf("Got: %lu\r\n", value);
    }
}
```

---

*优点: 比队列/信号量快45%，不消耗额外内存。*
*缺点: 只能用于1对1通信，无法用于多任务等待同一事件。*
