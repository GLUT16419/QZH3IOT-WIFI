# FreeRTOS 内存管理模块

包含：堆内存配置、heap_4特性、栈大小计算、总内存占用估算。

---

## 1. 堆内存配置

```c
// FreeRTOSConfig.h
#define configTOTAL_HEAP_SIZE   ((size_t)(12 * 1024))   // 12 KB
```

堆内存由 `heap_4.c` 在一个大数组中管理：

```c
// 文件: FreeRTOS/portable/MemMang/heap_4.c
static uint8_t ucHeap[configTOTAL_HEAP_SIZE];
// 起始: &ucHeap[0]
// 结束: &ucHeap[configTOTAL_HEAP_SIZE-1]
```

### heap_4 特性

| 特性 | 说明 |
|------|------|
| 分配 | `pvPortMalloc()` |
| 释放 | `vPortFree()` |
| 碎片处理 | 相邻空闲块自动合并 |
| 策略 | 首次适应 |
| 线程安全 | 分配/释放时自动关中断 |

## 2. 用户可直接使用的内存分配函数

```c
void *pvPortMalloc(size_t xSize);     // 分配内存
void vPortFree(void *pv);             // 释放内存
void *pvPortCalloc(size_t num, size_t size);  // 分配并清零
void *pvPortRealloc(void *pv, size_t size);   // 重新分配
```

## 3. 栈大小计算

```c
// 定义: configMINIMAL_STACK_SIZE = 256 字
// 1 字 = 1 StackType_t = 4 字节 (32位)
// 所以: 256 字 = 1024 字节

// 栈需求评估:
// 基础空任务:            ~100 字 (400字节)
// + 调用printf:          +100 字
// + 调用sprintf:         +200 字
// + 包含大数组(如char buf[128]): +40 字
// + 嵌套函数调用:        +20 字/层

// 查看栈使用量:
// UBaseType_t free = uxTaskGetStackHighWaterMark(xTaskHandle);
// free 返回剩余栈(字), 值越小越接近溢出
```

## 4. 总内存占用估算

### 固定消耗

| 项目 | 大小 | 说明 |
|------|------|------|
| 内核数据结构 | ~2KB | TCB列表、队列注册表等 |
| 空闲任务栈 | 256字 = 1KB | 由系统创建 |
| 定时器任务栈 | 512字 = 2KB | configTIMER_TASK_STACK_DEPTH |
| 定时器队列 | ~160字节 | configTIMER_QUEUE_LENGTH |

### 动态消耗

| 项目 | 大小 | 说明 |
|------|------|------|
| 每任务TCB | ~80字节 | 任务控制块 |
| 任务栈 | N字 × 4 | 由创建时的usStackDepth决定 |
| 队列 | 见下方公式 | |
| 信号量 | ~80字节 | 二进制/计数信号量 |
| 互斥锁 | ~80字节 | |
| 事件组 | ~60字节 | |
| 软件定时器 | ~60字节 | |

### 队列内存计算公式

```c
// 队列消耗内存 = sizeof(Queue_t) + (uxQueueLength * uxItemSize)
// sizeof(Queue_t) ≈ 80 字节
// 举例: xQueueCreate(10, sizeof(uint32_t))
//  = 80 + (10 * 4) = 120 字节
```

### 总内存示例: 3个任务 + 1个队列 + 1个互斥锁

```c
// 固定消耗:
//   内核            ~2000 字节
//   空闲任务栈      1024 字节
//   定时器任务栈    2048 字节
//   定时器队列       ~160 字节
//   小计            ~5232 字节

// 动态消耗:
//   3个任务TCB      3*80  = 240 字节
//   3个任务栈       3*1024 = 3072 字节 (假设各256字)
//   1个队列         80+10*4 = 120 字节
//   1个互斥锁        80 字节
//   小计            ~3512 字节

// 总计: 5232 + 3512 = 8744 字节 ≈ 8.5KB
// 剩余: 12KB - 8.5KB = 3.5KB
```

## 5. 栈溢出检测

```c
// FreeRTOSConfig.h 中已启用:
#define configCHECK_FOR_STACK_OVERFLOW  1

// 需要实现钩子函数:
void vApplicationStackOverflowHook(TaskHandle_t xTask, char *pcTaskName) {
    // 发生栈溢出时自动调用
    printf("Stack Overflow! Task: %s\r\n", pcTaskName);
    while(1);  // 停止
}
```

---

*建议: 每个任务至少分配 256 字 (1024字节) 的栈空间，含printf的任务至少 384 字。*
