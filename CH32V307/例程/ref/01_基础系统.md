# 基础系统模块

包含：芯片型号宏定义、基础数据类型、debug延时与printf、NVIC中断控制器、完整IRQ中断号列表。

---

## 1. 芯片型号宏定义

```c
// 在编译选项或代码中定义芯片型号（二选一）：
#define CH32V30x_D8              /* CH32V303x 系列 */
#define CH32V30x_D8C             /* CH32V307x / CH32V305x 系列（默认，带以太网） */
```

## 2. 时钟频率定义

```c
// 文件: Peripheral/inc/ch32v30x.h
#define HSE_VALUE    ((uint32_t)8000000)   // 外部高速晶振 8MHz
#define HSI_VALUE    ((uint32_t)8000000)   // 内部高速晶振 8MHz

extern uint32_t SystemCoreClock;           // 系统核心时钟频率（变量）
```

## 3. 基础数据类型

```c
typedef enum { DISABLE = 0, ENABLE = !DISABLE } FunctionalState;
typedef enum { ERROR = 0, SUCCESS = !ERROR } ErrorStatus;
typedef enum { RESET = 0, SET = !RESET } FlagStatus, ITStatus;
```

## 4. 调试与延时模块

### 头文件

```c
#include "debug.h"   // 文件路径: Debug/debug.h
```

### 调试串口宏

```c
#define DEBUG_UART1    1   // 使用 USART1 (PA9-TX, PA10-RX)
#define DEBUG_UART2    2   // 使用 USART2
#define DEBUG_UART3    3   // 使用 USART3
#ifndef DEBUG
#define DEBUG   DEBUG_UART1
#endif
```

### 函数原型

```c
void Delay_Init(void);
void Delay_Us(uint32_t n);     // 微秒级延时
void Delay_Ms(uint32_t n);     // 毫秒级延时
void USART_Printf_Init(uint32_t baudrate);  // 串口 printf 初始化
```

### 典型用法

```c
#include "debug.h"

int main(void) {
    SystemCoreClockUpdate();
    Delay_Init();
    USART_Printf_Init(115200);
    printf("SystemClk:%d\r\n", SystemCoreClock);
    printf("ChipID:%08x\r\n", DBGMCU_GetCHIPID());
    Delay_Ms(1000);
}
```

### 系统初始化模板

```c
#include "debug.h"

int main(void) {
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    SystemCoreClockUpdate();
    Delay_Init();
    USART_Printf_Init(115200);
    printf("SystemClk:%d\r\n", SystemCoreClock);
    printf("ChipID:%08x\r\n", DBGMCU_GetCHIPID());

    // 外设初始化...

    while(1) { }
}
```

## 5. NVIC - 嵌套向量中断控制器

### 头文件

```c
#include "ch32v30x.h"   // NVIC 函数在此文件中
```

### 中断优先级分组

```c
#define NVIC_PriorityGroup_0  ((uint32_t)0x700)  // 0位抢占, 4位子优先级
#define NVIC_PriorityGroup_1  ((uint32_t)0x600)  // 1位抢占, 3位子优先级
#define NVIC_PriorityGroup_2  ((uint32_t)0x500)  // 2位抢占, 2位子优先级
#define NVIC_PriorityGroup_3  ((uint32_t)0x400)  // 3位抢占, 1位子优先级
#define NVIC_PriorityGroup_4  ((uint32_t)0x300)  // 4位抢占, 0位子优先级

void NVIC_PriorityGroupConfig(uint32_t NVIC_PriorityGroup);
```

### NVIC API

```c
void NVIC_EnableIRQ(IRQn_Type IRQn);
void NVIC_DisableIRQ(IRQn_Type IRQn);
void NVIC_SetPriority(IRQn_Type IRQn, uint32_t priority);
uint32_t NVIC_GetPriority(IRQn_Type IRQn);
void NVIC_SetPendingIRQ(IRQn_Type IRQn);
void NVIC_ClearPendingIRQ(IRQn_Type IRQn);
```

### 典型用法

```c
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);  // 2位抢占, 2位子优先级
NVIC_EnableIRQ(USART1_IRQn);
NVIC_SetPriority(USART1_IRQn, 2);
```

### 中断函数命名

中断函数名在启动文件中固定，用户必须精确匹配：

```c
void NMI_Handler(void);                // 非屏蔽中断
void HardFault_Handler(void);          // 硬错误
void EXTI0_IRQHandler(void);
void TIM2_IRQHandler(void);
void USART1_IRQHandler(void);
void DMA1_Channel1_IRQHandler(void);
void ADC_IRQHandler(void);
// 规则: IRQn枚举名 + _IRQHandler
```
