## 2. 芯片型号差异速查

| 特性 | CH32V303 (D8) | CH32V305/307 (D8C) |
|------|---------------|--------------------|
| 编译宏 | CH32V30x_D8 | CH32V30x_D8C |
| 最大Flash | 256KB | 256KB/512KB |
| SRAM | 64KB | 64KB/128KB |
| 以太网MAC | 无 | 有 (支持RMII) |
| USB OTG FS | 无 | 有 |
| USB OTG HS | 无 | 有 (需外部PHY) |
| DVP摄像头 | 无 | 有 |
| PLL倍频方式 | PLLMul_2 ~ PLLMul_18 | PLLMul_3_EXTEN ~ PLLMul_16_EXTEN |
| PREDIV | 无 | 有 PREDIV1/2 |
| 启动文件 | startup_ch32v30x_D8.S | startup_ch32v30x_D8C.S |

## 3. 常用外设时钟使能汇总

### APB2 (高速外设)

| 外设 | 时钟宏 | 总线 |
|------|--------|------|
| AFIO | RCC_APB2Periph_AFIO | APB2 |
| GPIOA~E | RCC_APB2Periph_GPIOx | APB2 |
| ADC1/ADC2 | RCC_APB2Periph_ADCx | APB2 |
| TIM1/TIM8 | RCC_APB2Periph_TIMx | APB2 |
| SPI1 | RCC_APB2Periph_SPI1 | APB2 |
| USART1 | RCC_APB2Periph_USART1 | APB2 |

### APB1 (低速外设)

| 外设 | 时钟宏 | 总线 |
|------|--------|------|
| TIM2~7 | RCC_APB1Periph_TIMx | APB1 |
| USART2~3 | RCC_APB1Periph_USARTx | APB1 |
| I2C1~2 | RCC_APB1Periph_I2Cx | APB1 |
| SPI2 | RCC_APB1Periph_SPI2 | APB1 |
| CAN1 | RCC_APB1Periph_CAN1 | APB1 |
| DAC | RCC_APB1Periph_DAC | APB1 |
| PWR/BKP | RCC_APB1Periph_PWR / BKP | APB1 |

### AHB

```c
#define RCC_AHBPeriph_DMA1    ((uint32_t)0x00000001)
#define RCC_AHBPeriph_DMA2    ((uint32_t)0x00000002)
#define RCC_AHBPeriph_SDIO    ((uint32_t)0x00000400)
#define RCC_AHBPeriph_RNG     ((uint32_t)0x40000000)
#define RCC_AHBPeriph_OTG_FS  ((uint32_t)0x10000000)
#define RCC_AHBPeriph_CRC     ((uint32_t)0x00000040)
```
