## 📡 设备间通信协议（格式与Topic）

### 一、云端流转配置（已生效）
- **解析器脚本**（透明转发，不修改数据）：
  ```javascript
  var data = payload('json');
  writeIotTopic(1004, "/YOUR_PRODUCT_KEY/YOUR_DEVICE_NAME/user/get", data);
  ```

### 二、发送端（F407 / V307）→ 云端
- **发布 Topic**：  
  `/YOUR_PRODUCT_KEY/${deviceName}/user/update`
  - F407 示例：`/YOUR_PRODUCT_KEY/STM32F407/user/update`
  - V307 示例：`/YOUR_PRODUCT_KEY/CH32V307/user/update`
- **数据格式（JSON）**：
  ```json
  {
    "temperature": 数值,
    "humidity": 数值,
    "sourceDevice": "STM32F407"   // 或 "CH32V307"
  }
  ```
- **字段说明**：
  - `temperature`：温度（浮点数）
  - `humidity`：湿度（浮点数）
  - `sourceDevice`：**必填**，设备标识，固定字符串，用于接收端识别来源

### 三、云端 → 接收端（H3）
- **订阅 Topic**：  
  `/YOUR_PRODUCT_KEY/YOUR_DEVICE_NAME/user/get`
- **数据格式**：与发送端上报的 JSON **完全一致**（云端原样转发）

### 四、接收端（H3）解析规则
- 从 JSON 中读取 `sourceDevice` 字段：
  - 若值为 `"STM32F407"` → 数据来自 F407
  - 若值为 `"CH32V307"` → 数据来自 V307
- 业务字段（`temperature`、`humidity`）按需使用

---

### ✅ 核心约定
| 角色 | Topic | 关键字段 |
|------|-------|----------|
| F407 发送 | `/YOUR_PRODUCT_KEY/STM32F407/user/update` | `sourceDevice: "STM32F407"` |
| V307 发送 | `/YOUR_PRODUCT_KEY/CH32V307/user/update` | `sourceDevice: "CH32V307"` |
| H3 接收 | `/YOUR_PRODUCT_KEY/YOUR_DEVICE_NAME/user/get` | 读取 `sourceDevice` 区分来源 |
